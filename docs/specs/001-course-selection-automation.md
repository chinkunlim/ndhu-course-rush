# SPEC-001：東華大學自動選課與預排檢視

- **狀態**：Implemented
- **日期**：2026-10-22
- **相關任務 / ADR**：TASK-006 / ADR-001, ADR-002, ADR-003, ADR-004

## 1. 目標

協助國立東華大學學生在每學期線上加退選時段中，透過自動化工具大幅降低人工手動登入、繁瑣彈窗點擊與志願序點選所消耗的時間，在秒級甚至毫秒級的伺服器開放時段成功選中目標學分課程。

## 2. 使用情境

學生在加退選開放前，設定好帳號密碼並建立 `courses_info.md` 搶課順序，於開放時間透過命令列或 `main.py` 觸發全自動或半自動化加選流程。

## 3. 需求

- **必須 (Must)**：
  - 支援 Playwright 驅動原生 Chrome 瀏覽器。
  - 自動完成東華選課系統身分驗證並關閉教學意見調查彈窗。
  - 查詢預排課程並解析限修人數、已選人數與剩餘空位。
  - 匯出與讀取 `courses_info.md` 志願序設定。
  - 依志願序加選，支援人性化隨機微延遲防阻擋。
  - 非選課時段支援 Dry-Run 演練，按鈕不存在時安全跳過不崩潰。
- **可選 (Nice to have)**：
  - Headless 模式切換。
  - 僅查詢預排課表模式 (`--query-only`)。
- **不做 (Out of scope)**：
  - 繞過圖形驗證碼（CAPTCHA）行為。

## 4. 介面 / API

- 命令列入口：`uv run ndhu-course-rush` 或 `uv run python main.py`
- 設定檔：`.env`（`NDHU_USERNAME`, `NDHU_PASSWORD`, `LOGIN_URL`, `RUSH_DELAY`, `QUERY_DELAY`）
- 課表檔：`courses_info.md`
