# ISSUE-004：終端機日誌列印對反應時延之影響

- **狀態**：resolved
- **發現日期**：2026-06-03
- **Agent**：`system`
- **任務**：`TASK-006`

## 1. 現象

評估在關鍵搶課迴圈中，終端列印 `print()` 是否會拖慢毫秒級反應速度。

- **錯誤訊息**：無錯誤，屬於效能敏感分析。
- **影響範圍**：搶課迴圈時延。

## 2. 根本原因

在 macOS/Linux 終端環境下，單行 `print()` 耗時小於 0.05ms，相較於網路 RTT（10~30ms）影響極微；但過度冗長字串拼接與同步 I/O 仍應避免。

## 3. 修正或規避方式

嚴格分層：services 層僅使用 logging，只有 entrypoints 負責終端 stdout 輸出；搶課階段僅記錄關鍵動作。

## 4. 防回歸

分層架構規則（`ARCHITECTURE_RULES.md`）強制 services 層不使用 print。
