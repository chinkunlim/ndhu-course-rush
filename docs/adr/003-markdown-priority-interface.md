# ADR-003：採用 Markdown 文件作為優先級排程的人機互動介面

- **狀態**：Accepted
- **日期**：2026-06-02
- **Agent**：`system`
- **任務**：`TASK-006`

## 1. 背景與問題

使用者希望在終端執行時自訂選課優先順序，但終端命令列互動（如輸入一長串代碼或陣列）容易打錯字且無法直觀檢視限修人數與餘額。

## 2. 評估過的方案

| 方案 | 優點 | 缺點 |
|---|---|---|
| CLI 命令列逐一輸入 | 不需外部檔案 | 操作繁瑣、易打錯代碼、無法視覺化檢視名額與空位 |
| courses_info.md 表格 | 零學習成本、可視覺化檢視名額、選課前可反覆推敲最佳志願序 | 需在編輯器與終端間切換 |

## 3. 決策與理由

程式爬取預排課程後，動態寫入 `courses_info.md`，提供預設欄位「搶課順序」。
使用者在編輯器中修改數字並存檔，終端輸入 `2` 即直接解析該 Markdown 表格取得目標順序。

## 4. 影響與代價

- 零學習成本，表格視覺化極佳。
- 資料留底於本機，選課前可反覆推敲最佳志願序。
