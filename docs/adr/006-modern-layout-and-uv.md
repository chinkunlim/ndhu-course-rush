# ADR-006：導入現代分層架構與 uv 套件管理體系

- **狀態**：Accepted
- **日期**：2026-10-08
- **Agent**：`system`
- **任務**：`TASK-006`

## 1. 背景與問題

原專案為根目錄單檔 `auto_login.py`，缺乏模組化、單元測試與現代 Python 套件標準。

## 2. 評估過的方案

| 方案 | 優點 | 缺點 |
|---|---|---|
| 單檔腳本 | 簡易直接 | 無法模組化測試、維護成本隨複雜度暴增 |
| 現代分層結構 + uv | 高效管理虛擬環境與依賴、單元測試完整、分層清晰 | 需要標準目錄結構與規範 |

## 3. 決策與理由

重構為清晰的層級結構（`entrypoints ➔ adapters ➔ services ➔ domain ➔ config`），將瀏覽器驅動、身分認證、課表解析與搶課排程拆分模組。
採用 `uv` 鎖定 Python 3.11 及全部依賴，配置 `pyproject.toml` 與自動化測試。

## 4. 影響與代價

- 專案架構清晰健全，具備良好的可測試性與可擴展性。
