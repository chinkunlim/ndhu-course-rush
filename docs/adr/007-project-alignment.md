# ADR-007：專案結構標準化審計與規範對齊機制

- **狀態**：Accepted
- **日期**：2026-10-08
- **Agent**：`system`
- **任務**：`TASK-006`

## 1. 背景與問題

為確保多 Agent 協同開發時專案結構、程式註解、文件規範維持最高標準，需要具備自動化審計與防呆機制。

## 2. 評估過的方案

| 方案 | 優點 | 缺點 |
|---|---|---|
| 人工檢查 | 彈性高 | 容易遺漏、規範執行不一致 |
| 自動化審計工具 + 框架 guard | commit 前自動檢查、測試門檻嚴格、規範 100% 落地 | 初期需要建置規範腳本 |

## 3. 決策與理由

採用 `agentctl check` 與 `code-review-guard`，對程式註解、分層依賴、型別註解（mypy strict）、秘密檢測與目錄樹進行全自動化審查。

## 4. 影響與代價

- 代碼品質與規範一致性得到長久保證。
