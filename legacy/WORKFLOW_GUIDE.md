# WORKFLOW_GUIDE.md - 標準作業流程 (SOP) 與選課搶課實戰指引

本文件為選課作戰專用標準操作手冊（Standard Operating Procedure），涵蓋選課前準備、離峰模擬演練、開放前黃金 5 分鐘就位、以及突發狀況緊急應變。

---

## 📅 選課週期作戰時程表

```text
【開放前 1 天】─────────►【開放前 15 分鐘】───────►【開放前 2 分鐘】───────►【開放瞬間 (00秒)】
 離峰乾跑演練              啟動程式預抓課表           確認 courses_info.md       終端按下「2」全力搶課
 檢查 Playwright 驅動      登入並解除彈窗             就位等待伺服器開放
```

---

## 1. 開放前 1 天：環境檢查與離峰乾跑 (Dry-Run)

### 步驟 1.1：驗證虛擬環境與瀏覽器通道
```bash
uv sync
uv run pytest
```
確認所有單元測試為綠燈通過。

### 步驟 1.2：乾跑演練 (Dry-Run Test)
1. 確保 `.env` 或 `config.txt` 中的帳密正確。
2. 執行腳本：
   ```bash
   uv run auto_login.py
   ```
3. 觀察瀏覽器：
   - 是否順利進入登入頁並成功登入？
   - 是否有成功點擊「查詢預排課程」？
   - 是否有自動彈窗點擊各門課並輸出 `courses_info.md`？
4. 終端機顯示確認選單時，輸入 `2` 進行加選演練：
   - 此時因非選課時間，各科目應顯示 `⚠️ 編號 [X] 沒有可點擊的加選按鈕，跳過。`
   - 這代表按鈕檢測與排序邏輯 100% 正常，沒有崩潰。

---

## 2. 開放前 15 分鐘：課表檢閱與志願序排程

### 步驟 2.1：更新預排課程資訊
再次執行 `uv run auto_login.py`，讓系統刷新最新的已選人數與剩餘空位。

### 步驟 2.2：編輯 `courses_info.md`
打開 [courses_info.md](file:///Users/limchinkun/Desktop/PyTest/courses_info.md)，在最左側「搶課順序」欄位填入志願序：

```markdown
| 搶課順序 | 原編號 | 課程代碼 | 限修人數 | 已選人數 | 剩餘空位 | 課程名稱 |
| :---: | :---: | :--- | :---: | :---: | :---: | :--- |
| 0 | **0** | `CP__30000` | 30 | 19 | **11** | (學三)團體諮商 |
| 1 | **1** | `CP__30210` | 60 | 13 | **47** | (學三)心理學研究法 |
| 2 | **4** | `GC__3680AC` | 40 | 27 | **13** | (校核心)法語(一)AC |
|   | **5** | `GC__65250` | 155 | 7 | **148** | (校核心)創業管理導論 |
```
> 💡 **注意事項**：
> - 數字越小代表越優先點擊（如 0, 1, 2...）。
> - 若有課程不想選，將該列最左欄保持空白即可，系統會自動跳過。
> - 編輯完成後務必儲存檔案（`Cmd+S` 或 `Ctrl+S`）。

## 3. 開放前 2 分鐘：陣位就緒 (On-Position)

1. 終端機此時應停留在：
   ```text
   =============================================
   表格已成功讀取！共 8 列資料。
   準備好後，請選擇操作：
     1. 輸入 Y：按照剛才抓取的原始預設順序全自動點擊
     2. 輸入 2：讀取您修改過的 courses_info.md 裡面的排序
     3. 輸入 N：取消並結束程式
   請輸入您的選擇: 
   ```
2. 將終端機游標就定位，鍵入 `2` 但**先不要按 Enter**。
3. 對照標準時間（如行政院人事行政總處或天文台對時網頁），等待秒針倒數。

---

## 4. 開放瞬間 (00 秒)：觸發衝刺 (Rush Execution)

1. 當時間一到系統開放瞬間（例如 12:00:00），在終端機按下 **Enter**。
2. 程式將以極速（20ms~50ms 延遲）依序鎖定您在 `courses_info.md` 標註的目標加選按鈕。
3. 觀察瀏覽器畫面中彈出的加選成功對話盒（系統 handle_dialog 會自動確認）。

---

## 5. 異常應變處理 (Troubleshooting)

| 異常情境 | 現象說明 | 緊急處置方式 |
| :--- | :--- | :--- |
| **連線塞車逾時** | 伺服器無回應，頁面旋轉很久 | 不要狂按重整；Playwright 設有自動等候機制，若超過 15 秒請手動點擊瀏覽器重整按鈕 |
| **登入 Session 失效** | 畫面跳回登入頁或顯示超時 | 立即在終端按 `Ctrl+C` 中斷，重新執行 `uv run auto_login.py` 讓其重新登入 |
| **加選失敗（額滿/衝堂）** | 跳出「已額滿」或「衝堂」彈窗 | `handle_dialog` 會自動關閉提示，腳本會自動往下一個志願序衝刺，無需人工作業 |
