# 對話摘要：003 - Markdown 課表雙向同步與名額彈窗爬取

## 📌 階段概述
本階段開創了將「網頁動態資料」轉錄為「本機 Markdown 文件」的互動模式。讓使用者可以直接在本機編輯 Markdown 檔案來指定選課志願序，並自動萃取每門課的選課人數與剩餘空位。

## 🎯 使用者核心訴求
1. **本機記錄**：將抓取到的課程資料儲存至 `courses_info.md`。
2. **新增順序欄位**：在表格最左側加入「搶課順序」欄位，供使用者自行填寫數字（如 1, 2, 3）。
3. **動態名額爬取**：點擊課程代碼連結，攔截跳出的原生 alert 框，提取「已選課人數」。
4. **剩餘空位計算**：自動解析「限修人數」與「已選人數」，計算並高亮「剩餘空位」。

## 🛠️ 關鍵技術決策與架構變更
1. **點擊連結觸發 Alert 抓取人數**：
   - 依序點擊 `td:nth-child(2) a`，觸發學校系統的原生彈窗，正則表達式擷取如 `已選人數：19人` 中的數值。
2. **彈窗點擊後自動確認**：
   - 透過 `handle_dialog` 自動接收並儲存文字，點擊後等待 0.2~0.5 秒讓狀態恢復。
3. **Markdown 格式化生成器**：
   - 輸出標準 GitHub Flavored Markdown 表格，支援以 `**1**` 或純數字形式填寫優先序。

## ⚠️ 踩坑、阻礙與解決方案
- **問題**：若某堂課彈窗未及時彈出或點擊失敗，可能導致迴圈卡住或數值為空。
- **解法**：給予彈窗變數重置機制 `alert_msg_box["text"] = None`，並設定 fallback 預設值 `?`，確保整體迴圈穩定跑完所有列。

## 📊 產出產物與成果
- 產生 `courses_info.md` 模板與自動生成邏輯。
- 實現網頁預排清單與本機 Markdown 表格的資料同步。
