# 系統全域背景 (CONTEXT.md)

> 本文檔專供 AI Agent 或新加入的維護者快速吸收專案的核心脈絡與邊界。

---

## 1. 專案業務目標
協助國立東華大學學生在每學期競爭激烈的「線上加退選」時段中，透過自動化工具大幅降低人工手動登入、繁瑣彈窗點擊與志願序點選所消耗的時間，爭取在秒級甚至毫秒級的伺服器開放時段成功選中關鍵學分課程。

---

## 2. 目標網站技術特徵
- **網址**：`https://sys.ndhu.edu.tw/aa/class/subjselect/course_sele.aspx`
- **架構**：微軟 ASP.NET WebForms 架構，高度依賴 `__doPostBack` 機制。
- **認證方式**：傳統表單 POST，包含學號（`ed_StudNo`）與密碼（`ed_pass`）。
- **特異行為**：
  1. 登入後偶發彈出教學意見調查問卷彈窗（jQuery UI Dialog）。
  2. 點擊課程代碼查詢人數時，使用瀏覽器原生 JavaScript `alert()` 回傳字串（如 `本科已選人數：19人`）。
  3. 加選成功或失敗時，同樣以原生 `alert()` 回報結果。
  4. 非選課時間，表格中加選按鈕為不可見或不存在狀態。

---

## 3. 開發哲學與演進核心
1. **堅持真機可視化**：使用者必須能在螢幕上親自監控所有網頁動作。
2. **Markdown as Interface**：避免開發繁瑣的 Desktop GUI，直接以 Markdown 檔案作為資料呈現與人機互動介面。
3. **電競級微延遲**：兼顧極限手速與連線穩定度。
